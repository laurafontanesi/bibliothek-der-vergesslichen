# Fonts

The website's fonts, served from the site itself (no request to Google). Made from the TTF files of fonts.google.com: reduced to the Latin letters, punctuation, arrows and symbols the site uses, and saved as WOFF (`fontTools`). Source Code Pro is copied unchanged: its licence reserves the name "Source", so a reduced version could not keep it. All are under the SIL Open Font License 1.1 (https://openfontlicense.org); the licence texts, one per family with its copyright line, are next to this file (`OFL-VT323.txt`, `OFL-ZillaSlab.txt`, `OFL-RobotoCondensed.txt`, `OFL-SourceCodePro.txt`). Only Source Code Pro has a reserved font name.
